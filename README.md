# Smart Temperature Control System

## Overview
This project is a smart temperature control system developed using Cisco Packet Tracer and an SBC (Single Board Computer).

The system monitors room temperature and automatically controls the Air Cooler and Heating Element based on the detected temperature.

## Components Used
- SBC
- Temperature Sensor
- Air Cooler
- Heating Element
- LCD Display
- Temperature Monitor

## Working
- The Temperature Sensor continuously detects the temperature.
- If the temperature is **520 or above**, the Air Cooler is turned ON.
- If the temperature is **below 520**, the Heating Element is turned ON.
- The LCD displays the current system status as **AC-ON** or **HEATER ON**.
- The Temperature Monitor displays the detected temperature.

## Programming
The SBC is programmed using Python to read the temperature sensor and control the connected devices.

## Tools Used
- Cisco Packet Tracer
- Python

## Project Output
The system automatically maintains the room temperature by switching between cooling and heating based on the sensor reading.
